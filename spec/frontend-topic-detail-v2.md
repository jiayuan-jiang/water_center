# Frontend: Topic Detail Page v2

## Goal

When a user opens a topic, show three sections in order:
1. **Monthly document count** (trend chart — already exists, keep as-is)
2. **Sub-topic analysis** — labeled summaries with attitude + cited quotes
3. **Raw comments** — filterable by sub-topic; citation IDs in summaries link to specific comments

## New Data Files Required

Two types of output files, both generated by `build/build_subtopic_data.py`:

### Type 1 — Topic-level subtopic index: `frontend/public/data/subtopics/reddit/t{N}.json`

Contains the grounded summary for each subtopic plus the full list of comment IDs in that subtopic. Used to render SubtopicCards and to know which IDs belong to which subtopic.

```json
{
  "topic_id": 2,
  "subtopics": [
    {
      "subtopic_id": 0,
      "doc_count": 226,
      "label": "Identifying and discussing invasive zebra/quagga mussels",
      "attitude": "Informational with underlying concern",
      "summary": "Users discuss quagga mussels filtering Lake Michigan every two weeks [oivbqxv], noting ecological damage despite clearer water [oiuz8jz].",
      "key_quotes": [
        {
          "id": "oivbqxv",
          "quote": "filter the entire quantity of lake Michigan every 2 weeks",
          "note": "Captures the scale of mussel filtering impact"
        }
      ],
      "comment_ids": ["oivbqxv", "oiuz8jz", "m6d06lr"]
    }
  ]
}
```

### Type 2 — Per-subtopic comment list: `frontend/public/data/subtopics/reddit/t{N}_s{M}.json`

Loaded on demand when user clicks a subtopic. Contains the full comment list for that subtopic (all comments, not just top-60), sorted by score descending.

```json
{
  "topic_id": 2,
  "subtopic_id": 0,
  "label": "Identifying and discussing invasive zebra/quagga mussels",
  "comments": [
    {
      "id": "oivbqxv",
      "subreddit": "chicago",
      "score": 6,
      "date": "2025-04-01",
      "text": "Eh, it's cleaner because the quagga mussels...",
      "url": "https://reddit.com/..."
    }
  ]
}
```

This is the **method B** approach: subtopic comments are fetched separately and replace the default comment list when a subtopic is selected. When user deselects (back to All), the original top-60 list is restored from the already-loaded topic data.

Same file structure for Bluesky: `frontend/public/data/subtopics/bluesky/t{N}.json` and `t{N}_s{M}.json`.

## Data Build Script

New script: **`build/build_subtopic_data.py`**

```
Input:
  data/subtopics/overview.json              (Reddit)
  data/subtopics/grounded_summary.json      (Reddit)
  data/subtopics/topic_{N:02d}.csv          (per-topic: all comments with subtopic assignment)
  data/subtopics_bluesky/...                (same for Bluesky)

Output:
  frontend/public/data/subtopics/reddit/t{N}.json        (topic-level index, one per topic)
  frontend/public/data/subtopics/reddit/t{N}_s{M}.json   (per-subtopic comment list)
  frontend/public/data/subtopics/bluesky/t{N}.json
  frontend/public/data/subtopics/bluesky/t{N}_s{M}.json
```

Logic per topic:
1. Load `grounded_summary.json` → get subtopics with label/summary/attitude/key_quotes
2. Load `topic_{N:02d}.csv` → group rows by `subtopic` column
3. For the topic-level index: collect just comment IDs per subtopic → write `t{N}.json`
4. For each subtopic: collect full comment rows, sort by score desc → write `t{N}_s{M}.json`

Comment schema from CSV columns: `id, subreddit/source, score, created_utc→date, text` + reconstruct URL from platform + id.

## Frontend Changes

### 1. `DetailPanel.jsx`

New state:
```js
const [subtopicData, setSubtopicData]       = useState(null)   // topic-level index (t{N}.json)
const [activeSubtopic, setActiveSubtopic]   = useState(null)   // null = show all
const [subtopicComments, setSubtopicComments] = useState(null) // loaded on demand (t{N}_s{M}.json)
const [subtopicLoading, setSubtopicLoading] = useState(false)
```

Fetch topic-level index on topic change:
```js
fetch(`data/subtopics/${platform}/t${topic.id}.json`)
  .then(r => r.ok ? r.json() : null)   // graceful: topics without subtopics return null
  .then(setSubtopicData)
```

On subtopic select — fetch full comment list for that subtopic:
```js
function handleSubtopicSelect(subtopicId) {
  if (subtopicId === activeSubtopic) {
    // deselect: back to All
    setActiveSubtopic(null)
    setSubtopicComments(null)
    return
  }
  setActiveSubtopic(subtopicId)
  setSubtopicLoading(true)
  fetch(`data/subtopics/${platform}/t${topic.id}_s${subtopicId}.json`)
    .then(r => r.json())
    .then(d => { setSubtopicComments(d.comments); setSubtopicLoading(false) })
}
```

Displayed comments:
```js
// When a subtopic is active, show the on-demand fetched list
// When All, show the default top-60 list already loaded with topic data
const displayedComments = activeSubtopic !== null ? (subtopicComments ?? []) : data.comments
```

Render order:
```jsx
<TrendChart ... />
{subtopicData && (
  <SubtopicPanel
    subtopics={subtopicData.subtopics}
    active={activeSubtopic}
    onSelect={handleSubtopicSelect}
  />
)}
<CommentSectionHeader
  subtopics={subtopicData?.subtopics}
  active={activeSubtopic}
  onSelect={handleSubtopicSelect}
  loading={subtopicLoading}
/>
<div id="comment-list">
  {subtopicLoading
    ? <div>Loading…</div>
    : displayedComments.map(c =>
        <CommentCard key={c.id} comment={c} platform={platform}
          highlighted={citedIds.has(c.id)} />
      )
  }
</div>
```

Citation linking:  
The `[id]` tokens in `summary` are rendered as `<button>` elements that call `scrollToComment(id)`. Since cited IDs may be in the subtopic comment list (not the default top-60), clicking a citation in a SubtopicCard auto-selects that subtopic first if needed, then scrolls.

Cited IDs for highlighting:
```js
const citedIds = new Set(
  subtopicData?.subtopics.flatMap(st => st.key_quotes.map(q => q.id)) ?? []
)
```

## Graceful degradation

- Topics without subtopic data (no `t{N}.json` file): subtopic section hidden, comment list shows default top-60 as before
- Subtopic selected but `t{N}_s{M}.json` fails to load: show error state in comment area, keep subtopic card selected
- Citation `[id]` clicked while "All" is active and comment is not in top-60: auto-trigger subtopic selection for the subtopic that contains that ID, then scroll
- Citation `[id]` not found in any loaded comments: button shown but greyed out, no scroll
